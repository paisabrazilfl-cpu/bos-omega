## 2026-05-18 - Case-insensitive string search overhead in C
**Learning:** `strcasestr` performs character-by-character lowercasing of both the haystack and needle inside its internal loops, leading to O(N*M) character conversion and comparison overhead. When performing multiple keyword matches against a single haystack (such as in security risk assessment and tool resolution), this results in substantial CPU waste. Pre-normalizing the haystack (lowercasing it once) and utilizing the standard `strstr` function reduces the time complexity of the matching process to O(N) for normalization and O(M) for each search.
**Action:** Replace multiple `strcasestr` calls with a single lowercase pass (using a robust `normalize` function) and subsequent `strstr` calls on the pre-lowercased buffer.
