## 2025-05-22 - [Optimized String Search Performance]
**Learning:** In C applications where multiple case-insensitive substring searches are performed on the same input (e.g., keyword-based routing or risk assessment), pre-lowercasing the input string once into a local buffer and using `strstr` with lowercase needles is significantly faster (~4x) than multiple `strcasestr` calls. Each `strcasestr` call typically involves overhead for case-folding or repeated comparisons that are redundant when done multiple times.
**Action:** Identify functions with multiple `strcasestr` or `str_has` calls on the same variable and refactor them to use a single `str_tolower` pass followed by `strstr`. Ensure the local buffer size matches the application's maximum expected string length to maintain consistency.
